# SOLO LEVELING SYSTEM — Workout

Фанатская веб-версия концепции Solo Leveling System Workout (в стиле ARISE SOLO / "Solo Level : System").
Тёмный системный интерфейс с неоновым свечением: ежедневные задания, XP, уровни, ранги охотника (E → SS),
статистика, достижения, серии дней — и всё это в браузере.

> Fan project. Не является официальным продуктом. Solo Leveling © её правообладатели.

## Возможности

- **Пробуждение** — ввод имени охотника, быстрый старт, продолжение старого сохранения
- **Ежедневные задания** — счётчики (отжимания, пресс, приседания, подтягивания, бег, чтение, планка...) с кнопками +/−, быстрым добором и полосой прогресса
- **XP и уровни** — каждое выполненное задание даёт XP, уровни растут по нелинейной кривой
- **Ранги охотника E → D → C → B → A → S → SS (Monarch)** — с анимацией повышения ранга и конфетти
- **Идеальный день** — выполни все задания и получи бонус +200 XP
- **Серия дней (streak)** и лучший стрик
- **Характеристики** — Сила, Скорость, Выносливость, Интеллект растут с уровнем и повторениями
- **Статистика** — график XP за 14 дней, общая статистика, путь рагов
- **Достижения** — 16 наград за цели разных уровней
- **Звуки и вибрация** (WebAudio, без файлов), отключаются в настройках
- **Экспорт/импорт JSON** и полный сброс прогресса
- **Язык RU/EN**, мобильная вёрстка, работа без интернета (localStorage)

## Запуск

Просто откройте `index.html`. Для локального сервера:

```bash
python3 -m http.server 8000   # или любой другой статический сервер
```

Деплой на GitHub Pages из ветки `main` / корня репозитория (включено).
