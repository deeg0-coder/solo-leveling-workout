# SOLO LEVELING SYSTEM — Workout

Фанатская веб-версия концепции Solo Leveling System Workout (в стиле ARISE SOLO / "Solo Level : System").
Тёмный системный интерфейс с неоновым свечением: ежедневные задания, XP, уровни, ранги охотника (E → SS),
статистика, достижения, серии дней — и всё это в браузере.

> Fan project. Не является официальным продуктом. Solo Leveling © её правообладатели.

## Возможности

- **Пробуждение** — ввод имени охотника, быстрый старт, продолжение старого сохранения
- **Ежедневные задания** — счётчики (отжимания, пресс, приседания, подтягивания, бег, чтение, планка, контрастный душ, растяжка) с кнопками +/−, быстрым добором и полосой прогресса
- **XP и уровни** — каждое выполненное задание даёт XP, уровни растут по нелинейной кривой
- **Ранги охотника E → D → C → B → A → S → SS (Monarch)** — с анимацией повышения ранга и конфетти
- **Идеальный день** — выполни все задания и получи бонус +200 XP и +50 монет
- **Серия дней (streak)** — каждые 7 дней непрерывной серии добавляют +25 монет; отслеживается лучший стрик
- **Характеристики** — Сила, Скорость, Выносливость, Интеллект растут с уровнем и повторениями, а также прокачиваются очками навыков (даются за уровень)
- **Скрытые задания** — система может случайно выдать секретный квест за выполнение (до 1 в день)
- **Тренировки** — журнал подходов по любому упражнению из библиотеки (журнал, PR-рекорды, XP за подход)
- **Фокус-таймер** — Pomodoro-сессии по 15/25/45 минут с наградой XP
- **Магазин** — монеты за задания/идеальные дни/скрытые квесты: 4 титула и 5 тем портала (скины меняют цвет фона и ауры)
- **Управление заданиями** — добавление, удаление и восстановление стандартного набора
- **Статистика** — график XP за 14 дней, календарь достижений, общая статистика, путь рангов
- **Достижения** — 24 награды за цели разных уровней
- **PWA** — устанавливается на главный экран (manifest, иконки, service worker, офлайн-кэш)
- **Звуки и вибрация** (WebAudio, без файлов), отключаются в настройках
- **Экспорт/импорт JSON** и полный сброс прогресса
- **Язык RU/EN** — полная локализация всех экранов, мобильная вёрстка, работа без интернета (localStorage)

## Запуск

Просто откройте `index.html`. Для локального сервера:

```bash
python3 -m http.server 8000   # или любой другой статический сервер
```

Деплой на GitHub Pages из ветки `main` / корня репозитория (включено).
